# Landing DVS – Kit mayorista de cosmética para farmacias

Maqueta HTML5 + CSS3 + JS (sin dependencias). Datos de relleno.

## Estructura
```
dvs-landing/
├── index.html
├── css/styles.css
├── js/main.js
└── README.md
```

## Ver en local
Abrí `index.html` en el navegador.

## Conectar el formulario
Editá `ENDPOINT` en `js/main.js` con la URL de tu servicio de formularios.

## Medir por provincia y anuncio
Usá enlaces con `?utm_source=meta&utm_medium=cpc&utm_campaign=kit-cordoba`.
